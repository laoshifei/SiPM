# 波形质量与混合形状模型的第二轮结果

**历史队列说明：** 下文保留原 phase2 样本、固定 PCA/背景条件下的区间和全部数值。2026-10-28 正式论文分析已在后续冻结的 40795 条队列上重新训练，并在每次配对重采样中重估 PCA 与背景参数，见[当前分析入口](README.md)和[论文工作稿](MANUSCRIPT_DRAFT.md)。两套队列的 FOM 和误差不能交叉组合。

本轮完成了已确认的 8 个 PHA run 的前触发检查，以及名义 53.2 V 下 run 3、12、18 的方法和记录窗口比较。用户进一步确认 ²⁴¹Am 测量中可见 α 信号；²⁴¹Am 的 γ 成分继续保留，逐事件标签仍未建立。以下 FOM 描述模型中两个统计形状成分的间隔，不能解释为 α 接受率、γ 泄漏率或样本纯度。

主要结果是：记录终点从 1 μs 延长到 4 μs 时，三种方法的形状 FOM 均提高；从 3 μs 延长到 4 μs 的增益已经小于较短记录区间的增益。平均时间和 PCA 投影相对简单积分比有一定改善，但排序随积分分箱和记录窗口变化。与此同时，run 12 内存在明显的基线噪声变化，run 18 的峰宽也与固定训练峰形不同，不能把全部测量当成一个稳定条件。

2026-10-28 的较早后续检查曾将本节训练的 3 μs 方法和 PCA 权重原样用于 8 个 run 的冻结诊断样本，没有重新训练或改写下面的 FOM。该阶段新增的幅度、状态位和前触发支持条件，以及局部协方差和原生响应候选见[模拟历史报告](../../simulation/RESULTS.md)。当前工作稿采用本页开头所述的新正式队列结果。

## 数据范围与划分

来源和排除清单沿用 [labels.csv](labels.csv)。质量检查覆盖 run 3、7、10、11、12、13、14、18，共 468,496 条原始波形；run 9、21、22、24、25 不进入本轮分析。

算法比较只使用 run 3、12、18。共同参考积分区间沿用第一轮结果 **201,824.1125–418,733.2 ADC·sample**，固定为六个等宽分箱。参考积分仍取第一轮的约 −40 至 +3000 ns 窗口，没有为获得更高 FOM 重新选择数据区间。比较要求四个长窗口都完整，因此各方法使用相同的可用事件。

| 阶段 | 数据范围 | 用途 |
| --- | --- | --- |
| 训练 | run 3、12 各自原始事件序号的前 60% | PCA 权重、统计峰形和方法 FOM |
| 中段检查 | 上述两轮的 60%–80% | 冻结峰形后的源测分布检查 |
| 后段检查 | 上述两轮的后 20% | 检查采集顺序变化和模型迁移 |
| 跨 run 检查 | run 18 | 保持训练峰形，另估混合权重并检查偏差 |

训练区在共同积分范围内有 run 3 的 2,529 条和 run 12 的 1,624 条事件。run 18 没有参与 PCA 或共享高斯峰形的训练。它已在第一轮中用于探索图，因此这里不是从未查看过的盲测；每轮前 20% 的基线数据还用于该轮的噪声参考标定。

## 前触发检查及其敏感性

噪声参考取各 run 前 20% 事件的前 128 点基线 RMS 的中位数，并与逐事件相邻差 MAD 估计及 1 ADC 下限取最大值。在 `[0, a−64)` 内计算 32 点移动均值的最大跨度，其中 a 为第一轮确定的整数前沿锚点。

当跨度同时超过 `k × 噪声参考` 和 `f × 峰值幅度` 时标记前触发不稳定。宽松、默认、严格条件分别为 `(k,f)=(12,0.05)、(8,0.03)、(5,0.015)`。检查只依赖前触发波形，没有使用源名称、积分比或预期的粒子类别。

初版仅使用相邻差噪声，得到的尺度约为 1 ADC，明显小于实际基线 RMS 的约 3–5 ADC，因而对相关及低频起伏过于敏感。修订采用基线参考；[初版协议](results/phase2/protocol_v1.json)、[初版计数](results/phase2/quality_counts_v1.csv)和逐事件旧标志都保留，没有把初版的大量剔除解释为更高纯度。当前规则见 [protocol.json](results/phase2/protocol.json)。

| 条件 | 8 个 run 的保留事件数 |
| --- | ---: |
| 原始保存波形 | 468,496 |
| 第一轮基础诊断通过 | 468,329 |
| 四个比较窗口均可用 | 468,321 |
| 再通过默认前触发检查 | 467,494 |

在共同积分区间内，默认条件分别保留 run 3、12、18 的 **4,257、2,549、108,276** 条事件。完整计数见 [quality_counts.csv](results/phase2/quality_counts.csv)。这个保留比例没有计入未触发或未保存的事件，不是探测效率。

对于第一轮定义的诊断带，⁶⁰Co run 3 低比值带的 42 条在三档条件下全部保留。²⁴¹Am run 18 高比值带的 13 条，在宽松、默认、严格条件下分别剩 6、1、0 条。这说明其中多数事件对前触发稳定性条件敏感；它既不把剩余事件自动标为 γ，也不把删除事件自动标为堆积。见 [band_retention.csv](results/phase2/band_retention.csv)。

另存峰后明显再次上升的候选标志：在峰后至少 80 点处，16 点移动均值相隔 32 点的上升超过 `max(8×参考噪声, 0.15×幅度)`。该条件尚不是经过实验标记验证的堆积识别，默认分析不据此删除事件。负尾部本身也不构成剔除条件。

对 3 μs 终点的积分比，改用严格前触发条件后，六个分箱的模型 FOM 相对默认条件最多变化 **1.37%**；改用更靠近前沿的基线估计，最多变化 **1.80%**；额外排除再次上升候选，最多变化 **0.51%**。本轮考察的宽背景尺度变化影响很小。这些结果描述指定数据和规则下的敏感性，不证明异常识别已完整。见 [sensitivity_checks.csv](results/phase2/sensitivity_checks.csv)。

## run 12 的噪声状态变化

按采集顺序分成 20 块，run 12 后段的基线 RMS 明显升高。对 `log(RMS)` 作一个分界的描述性扫描，候选位置在**事件索引 5029，从 0 开始计数**，约占保存事件序列的 66.9%。分界前后基线 RMS 的中位数分别为 **3.17 和 5.86 ADC**，后者约为前者的 1.85 倍。

同一分界搜索也对控制数据运行，但算法总会返回一个候选点，不能把它们全部当成真实状态变化：run 3 的前后中位数比约 0.950，run 18 约 1.005；run 12 的变化明显更大。记录在 [noise_change_candidates.json](results/phase2/noise_change_candidates.json) 和 [time_blocks.csv](results/phase2/time_blocks.csv)。没有据此推断温度、偏压或具体硬件故障。

run 12 前 60% 训练段位于这次明显升高之前；后续段的默认保留比例约降至 80%。这些后段事件仍保留在数据和诊断中，没有因为结果不理想而整段删除。

## 三种方法和统计模型

三种指标使用相同的基线、前沿和事件范围：

1. **积分比**：`R = Qshort / Qlong`，短窗为 `[a−20,a+250)`，长窗终点依次为 a+500、a+1000、a+1500、a+2000。
2. **平均时间**：在相同长窗内计算基线扣除信号的时间一阶矩除以积分；没有把负噪声样本截成零。为统一图中高低方向，模型使用平均时间的相反数。
3. **PCA 投影**：将对齐波形按 20 点分块，以该长窗积分归一化，提取训练数据的第一主成分。训练时每个 run、每个积分分箱等权；投影方向只按训练积分比相关性的正负统一，未生成逐事件粒子标签。

时间终点为 1、2、3、4 μs；各窗实际都还包含约 40 ns 的前沿前段，总窗口约为 1.04–4.04 μs。PCA 模型和训练单元计数见 [pca_models.json](results/phase2/pca_models.json)。

每个积分分箱使用两个高斯核心 L、H，以及一个宽 Cauchy 扰动项。高斯位置和宽度在训练 run 3、12 之间共享，各 run 的混合权重分别估计。L/H 只表示排序后的统计成分；宽扰动项也不是实测本底谱。全部有限指标值参与拟合，没有按高低 PSD 分数预先删除尾部。

FOM 定义为

\[
\mathrm{FOM}=\frac{|\mu_H-\mu_L|}{2\sqrt{2\ln 2}\,(\sigma_H+\sigma_L)}.
\]

72 个“方法×窗口×积分分箱”拟合均收敛，均未触及数值宽度下限。在相同观测量、相同事件和固定宽扰动形状下，单核心与双核心模型的条件 BIC 差最小约 308，支持使用两个统计形状核心描述这组联合源数据。这不是对两个物理粒子类别的独立标记，也不能跨不同指标直接比较绝对 BIC 或对数密度。

3 μs 终点的 18 个模型各进行了 128 次、每块 64 个原始事件的分块 bootstrap，共 2,304 次拟合成功。区间以已经学习的 PCA 和宽扰动形状为条件，没有包含它们的全部学习不确定度。详细参数和边界状态见 [mixture_models.json](results/phase2/mixture_models.json)。

## 窗口和方法的结果

下面是六个共同积分分箱的 FOM **中位数**，不是把全能区投影拟合后得到的 FOM：

| 窗口终点 | 积分比 | 平均时间 | PCA 投影 |
| --- | ---: | ---: | ---: |
| 1 μs | 1.251 | 1.376 | 1.361 |
| 2 μs | 1.988 | 2.189 | 2.119 |
| 3 μs | 2.397 | 2.656 | 2.559 |
| 4 μs | 2.627 | 2.825 | 2.808 |

在 3 μs 终点下，六个分箱的 FOM 范围分别为 **1.98–3.01、2.18–3.32、2.15–3.32**。平均时间和 PCA 并非每个分箱都按同一顺序排列，条件置信区间也有重叠，因此不宣称某一种复杂方法普遍优于另一种。

从 3 μs 延长到 4 μs 时，三种方法的分箱中位 FOM 分别提高约 9.6%、6.3%、9.8%，同时积分记录样本数增加约三分之一。4 μs 是本轮扫描中最长的终点，现有波形不能据此证明更长窗口无益，也不能把 3 或 4 μs 写成普适最优值。逐箱结果见 [method_comparison.csv](results/phase2/method_comparison.csv)。

## 跨 run 复核的限制

run 18 的检查冻结训练得到的峰形，只重新估计该 run 的混合权重。3 μs 积分比模型在六个分箱的直方图总变差距离约为 **0.029–0.097**；给定固定模型、相同样本量的抽样参考 99% 分位约为 **0.016–0.020**。这提示固定峰形仍有系统偏差。

该参考由 2,000 次多项分布模拟得到，没有计入训练参数不确定度、重新估权重和序列相关性的全部影响，不能当成已校准的拟合优度 p 值。小样本时间检查段的距离本来就可能较大，不能仅比较距离大小就认定失稳。见 [fit_sampling_reference.csv](results/phase2/fit_sampling_reference.csv)。

检查后的描述性重拟合表明，run 18 主要低比值核心的位置相对训练值变化约 0.05–0.15 个训练标准差，宽度约为训练值的 **0.82–1.01 倍**。因此“主要波形形状相近”与“可共享完全固定的峰宽”是两项不同结论。见 [qdc_main_shape_drift.csv](results/phase2/qdc_main_shape_drift.csv)。这次重拟合不能反过来算作模型已经独立预测成功。

²⁴¹Am 检查数据中，H 核心的拟合权重在许多分箱落在零边界。它只表示本模型在该已保存、已筛选的积分范围内未解析出相应统计核心，不表示 ²⁴¹Am 不发射 γ，也不能据此宣称样本纯 α。模型成分、源成分和事件真值仍需区分。
