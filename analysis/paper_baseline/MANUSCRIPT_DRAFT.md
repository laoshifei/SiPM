# CsI(Tl) SiPM 源测波形的记录窗口与形状指标比较

方法与结果草稿，基于 2026-10-27 已完成的探索性分析。尚未包含完整实验装置描述和物理粒子标签验证，不能作为已完成的 α/γ 效率论文提交。

## 研究问题

在既有 CsI(Tl) 与 SiPM 源测数据中，研究有限记录窗口下不同波形形状指标的分离能力，并检查基线状态和跨 run 差异对比较结果的影响。电荷比较与加权波形处理的已有研究表明，时间对齐、窗口与滤波条件需要在同一读出链和相近光输出下评估；其他读出器件的最佳参数不能直接移植到本系统。[本地文献与核验位置](LOCAL_EVIDENCE.md)

本研究将放射源身份与逐事件粒子身份分开处理。²⁴¹Am 测量中确认可见 α 信号，同时包含 γ 辐射。源条件用于约束统计分布的比较，不将一整轮 ²⁴¹Am 数据标为纯 α 样本。

## 实验数据

已确认来源的 PHA CH0 数据包含 8 个 run，共 468,496 条波形。⁶⁰Co 测量为 run 3、7，名义偏压分别为 53.2、53.4 V；²⁴¹Am 测量为 run 10、11、12、13、14、18，名义偏压依次为 52.4、52.8、53.2、53.6、54.0、53.2 V。每条波形包含 2496 个采样点，按本地配置对应 2 ns/点。run 3、12、18 使用同一晶体、SiPM 和接线，因此算法比较优先限制在这三个名义 53.2 V 数据集。

从每条 BIN 波形保存的硬件能量重建直方图，与同目录历史能谱逐 bin 核对，包括上下溢出。部分 run 的波形对应较早的能谱快照，与目录中较新的 `run.info` 不同。因此本文不据最新 `run.info` 推算这些波形的活时间或计数率，当前触发配置与旧波形的关联也保留说明。

晶体尺寸及 α 入射结构、SiPM 型号与数量、读出放大器及增益、放射源封装和几何、温度与能量刻度尚需实验记录补全；本草稿不为这些字段代入典型值。装置描述和表格来源见 [EXPERIMENT_INFO.md](../../EXPERIMENT_INFO.md)。

## 波形处理与比较范围

逐事件以前 128 点均值估计基线。采用主峰之前的 10% 幅度上升交点确定对齐时刻，并在固定前沿锚点附近设置嵌套积分窗。参考长积分取约 −40 至 +3000 ns。run 3、12、18 的中央积分覆盖交集为 201,824–418,733 ADC·sample，将其固定划分为六个等宽区间。

质量检查包括记录完整性、ADC 数值边界、信噪比、积分窗完整性和前触发稳定性。前触发检查使用基线数据校准的噪声参考，并比较宽松、默认和严格条件。负尾部及峰后再次上升分别保留为诊断量，默认分析不因尾部为负或再次上升标志而自动删除事件。默认条件在共同积分区间内保留 run 3、12、18 的 4,257、2,549、108,276 条事件。

比较三种指标：短长积分比、长窗内信号时间一阶矩，以及对归一化分块波形学习的第一主成分投影。短积分终点为前沿后约 500 ns；长窗终点依次为 1、2、3、4 μs，均包含约 40 ns 的前沿前记录。各方法使用相同事件及参考积分分箱。

PCA 权重仅由 run 3、12 各自前 60% 的事件训练，每个 run 和积分分箱等权。随后 20% 和最后 20% 用于时间分段检查，run 18 用于跨 run 复核。各 run 已在前期探索中查看过，因此这些结果作为内部一致性与迁移检查报告，不称为未接触过的盲测。

## 统计形状模型

在每个参考积分区间内，以共享位置和宽度的两个高斯核心描述联合源数据的主要形状结构，各 run 分别拟合混合权重，并加入一个宽 Cauchy 扰动项。两个核心按指标从低到高记作 L 和 H，不直接命名为 α 和 γ。定义形状 FOM 为核心间距除以两核心 FWHM 之和。

3 μs 终点的 FOM 区间由分 run 的 64 事件块 bootstrap 估计，每个拟合使用 128 次重采样。该区间以已学习的 PCA 权重和宽扰动密度为条件，不包含物理标签不确定度，也不转换为事件识别效率。

## 初步结果

三种方法的分箱 FOM 中位数均随扫描记录终点增加而提高。积分比方法在 1、2、3、4 μs 终点下的中位 FOM 分别为 1.251、1.988、2.397、2.627；平均时间为 1.376、2.189、2.656、2.825；PCA 投影为 1.361、2.119、2.559、2.808。结果支持在当前记录范围内保留较晚波形信息，但不证明 4 μs 是普适最优终点。[方法比较图](results/phase2/phase2_methods.png)

3 μs 下，积分比、平均时间和 PCA 的六个分箱 FOM 范围分别为 1.98–3.01、2.18–3.32 和 2.15–3.32。方法排序随分箱变化，条件区间存在重叠。额外质量条件和替代基线估计对积分比 FOM 的最大相对影响在本轮考察范围内不超过约 1.8%，但这不等于异常事件与粒子成分均已完整辨认。

run 12 在约 66.9% 的采集顺序处出现基线噪声变化，分界前后 RMS 中位数约为 3.17 和 5.86 ADC。源数据不能仅凭相同 run 标签视作完全稳定的采集状态。[质量检查图](results/phase2/phase2_quality.png)

将训练峰形用于 run 18 时，主要低比值核心位置相近，但部分分箱的宽度存在差别；描述性重拟合的宽度约为训练宽度的 0.82–1.01 倍。固定峰形下的分布偏差也高于仅考虑固定模型抽样的参考尺度。这提示后续模型需明确处理 run 间峰形变化，而不能只重新调整混合权重。[跨 run 检查图](results/phase2/phase2_transfer.png)

## 当前结论边界

这些结果适合支持有限记录窗口和波形指标的条件比较。两个统计核心的物理归属、²⁴¹Am 中 γ 成分的可辨识范围、源测本底以及独立粒子标记仍需进一步论证。当前不报告 α 接受率、γ 泄漏率、真实样本纯度、keVee 甄别阈值或温度稳定性。

完整数值、拟合假设、质量规则修订、软件检查及复现命令见 [第二轮分析报告](PHASE2_RESULTS.md)。
