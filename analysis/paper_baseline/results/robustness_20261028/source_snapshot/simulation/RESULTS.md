### 原生响应：保持雪崩电荷的双路径候选

新增 [ReadoutResponse](src/ReadoutResponse.cc) 及对应头文件，由原 `G4VDigitizerModule` 调用，ROOT schema 升为 **8**。其条件响应为 `(1−f)×原慢路径 + f×快路径`，两支均以相同雪崩电荷归一。原慢路径为 2 / 29 ns SPE 加 94.47 ns 额外 RC；快路径固定 2 / 5 ns、无额外 RC，扫描的 f 是**积分电荷份额**，不是峰值份额。默认缺省或 f=0 保持原响应；有限窗积分加尾部电荷守恒。

这是一组受等效电路快慢响应启发的线性候选，**尚非依据实际求和拓扑和元件值建立的完整电路**。Corsi 2007 支持考虑寄生电容、未触发微胞和负载，Garutti 2021 支持分开处理放电序列、单位面积响应和电子学卷积；二者均不提供本装置的快分量、增益或 PDE。核验范围和未采用的公式疑点见[本地证据](../analysis/paper_baseline/LOCAL_EVIDENCE.md)。

用新增 C++ [replay_response](replay_response.cc) 重放此前 **2000 个 Co / 12000 个 Am 的完整 Geant4 光子历史**，每个原始衰变均保留。重新执行原生 PDE、恢复、候选后脉冲及读出；几何、光学、采样、增益和电子噪声保持冻结。八份基础重放包括原响应、纯快路径基函数和 0.15 / 0.30 后脉冲提议概率；时延沿用 60 ns。这些是相同 14000 个输运历史的相关重放，不能累计为新的独立 MC 统计。平铺微胞映射不保留真实邻接，空间串扰继续禁用。

原响应重放的 **14000 条 ADC 和雪崩序列逐元素相同**，纯快路径的雪崩序列也不变；[八份完整性检查](results/response_candidates_20261028/integrity.json)全部通过。快份额扫描用原生两支输出线性组合，保留同一电子噪声后重新量化 ADC，并为每个候选重算事件选择。选中 f=0.10 后再用原生 C++ 重放全部历史，**与线性筛选的全部 ADC 样本完全相同**，共同 Q 事件编号也相同。

### 验证与本轮结论

`ctest` 的 4 个目标通过，包含 **14 项继承内核、3 项噪声、5 项双路径响应、10 项 Geant4 工作流检查**；另有 **5 项协方差、3 项冻结 PSD、1 项覆盖双源多候选的重放集成检查**通过。测试和实际运行的区别保留：电荷守恒、来源及逐点重放一致性属于工程核查，不能代替实测响应验证。日志与源码归档见[本轮记录](results/response_candidates_20261028/record.json)。

当前没有通过联合检查的候选，因此本轮不为失败候选追加大量独立完整输运，也不把快速份额或后脉冲概率发布为测得参数。论文草稿已把**记录窗口 / 固定方法的条件比较**与**尚未完成验证的前向模拟**分别表述。继续使用现有数据时，应先在现有局部协方差、形状与 Q 谱约束下检验有电路或采集依据的模型修正；仅提高 MC 数量不能消除当前系统性偏差。

### 条件参数扫描给出的边界

新增两极点形状与有效 ADC 面积的平稳散粒噪声扫描，固定 2 ns 上升极点，对单雪崩衰减和额外 RC 作网格扫描。下面保留首次以三个尺度中位数作比较的描述性扫描，目标是对数相对偏差，**不是 χ² 或似然**。两个极点的频域因子可以互换，此统计量无法独自确定它们分别属于 SiPM 还是外部电路。后续原生 MC 核查明确了均值 / 中位数的区别，工具现已默认使用事件比值的均值，见下节。

![响应退化与同偏压冲突](results/bias_response_profile_20261028_final/response_profiles.png)

在该近似内，run 3 / 12 使用同一个响应形状和有效面积时，最优预测仍分别比实测高约 **55%–74%**、低约 **37%–42%**。若允许两个 run 使用不同有效面积，三个尺度可逼近到约 6% 内，但这不能证明真实 SiPM 增益随放射源改变。即使只比较 Am 的 run 12 / 18，共同响应近似仍有约 **18%–30%** 偏差。

### Geant4 有限上升时间的受控检验

在现有 `DetectorConstruction`、`PhysicsList`、`RunConfig`、`RootIO` 中增加可选的有限上升时间。缺省 `[0,0]`，旧配置行为保持不变；schema 6 记录实际开关与参数。它使用原生 Geant4 光子发射时间抽样，仍包含 Am 的 α、γ 和次级电子，没有复制实测模板。

根据 [Geant4 11.4.2 源码](https://github.com/Geant4/geant4/blob/v11.4.2/source/processes/electromagnetic/xrays/src/G4Scintillation.cc#L557-L570)，有限上升时间密度正比于 `(1-exp(-t/rise))*exp(-t/decay)`。将原 RC 极点 94.4717 ns 移入发光抽样，需要 rise = RC×decay/(decay−RC)，即 117.696 / 101.455 ns，同时读出额外低通置零。连续线性平均响应数学等价，单条波形的涨落不同；完整 MC 的恢复效应、有限窗和对齐选择仍需比较。

![按模拟衰变来源拆分的电荷谱](results/corrected_optics_20261027/diagnosis/charge_by_origin.png)

本轮诊断得到：

- Co 的 125 个通过质量筛选的事件中，84 个由衰变电子后代贡献 ≥90% 雪崩电荷，36 个由 γ 后代主导，5 个混合。衰变电子包括 β、转换及原子退激电子。无封装源与实际触发选择是低电荷部分的重要待检验因素；不能直接删掉这些事件以追求吻合。
- Am 的 146 个质量合格事件中，92 个由 α 后代主导，39 个由 γ 后代主导。α 主导 MC 的积分电荷中位数约 742513 ADC·sample；实测 Am 训练总体中位数约 204444，后者没有逐事件 α 真值，不能据此直接求“α 淬灭系数”。
- 所有 Am 模拟中，α 后代产生的雪崩电荷约 **18.9%** 来自次级电子所发光子。当前 Geant4 粒子相关模型让这些电子使用电子的发光时间和产额。因此改变 α 光产额还会改变快慢成分混合，幅度和形状必须联合检验。

两种源在 80/120/160/200 ADC 峰值标记下的敏感性数值已写入[来源诊断](results/corrected_optics_20261027/diagnosis/diagnosis.json)。**总体幅度、电荷谱与触发选择的一致性仍未通过。** 此次修正没有通过按源缩放或删除物理成分掩盖差异。

### 接下来标定的具体顺序

1. 在已有配置与记录中约束源封装、接入通道、求和负载和触发；无法确认的量保留为候选场景。距离扫描单独不足以确定真实源距。
2. 在 run 3 / 12 训练段联合约束共享输出尺度与读出响应、源距和粒子相关光产额；显式保留 α 次级电子发光贡献。以未缩放 ADC 波形、Q 谱和短长门比同时判定，避免只优化归一化均值。
3. 冻结候选参数后再增加共同 Q 内的 MC 事件，并检查后段与 run 18。给出已探索检查的边界，继续保留 Am γ、源成分和选择条件差异。

## 平均形状

![平均波形与残差](results/comparison/waveform_comparison.png)

训练仅使用 run 3 / run 12 前 60%；下表为剩余后段及 run 18。共同 Q 区间固定为 201824.1125–418733.2 ADC·sample，每条波形按 t₁₀ 对齐、除以 [−40,3000) ns 面积。误差在 0–3500 ns 计算：`sqrt(mean((MC_mean − data_mean)^2)) / max(data_mean)`。这衡量平均形状，不衡量逐事件幅度或整体模型拟合概率。

| 实测检查组 | 实测平均使用事件数 | MC 平均使用事件数 | MC 峰值归一化 RMSE | 最大点残差 / 峰值 | MC 重采样 RMSE 95% 区间 |

| Am，run 18 | 1200 | 6 | 1.59% | 4.80% | 1.40–2.27% |

MC 总计为 Co 400 次、Am 240 次父核衰变；共同 Q 区间只剩 14 / 6 个事件。不能把这点统计量当成精确模型检验。重采样区间来自 1000 次整事件 bootstrap，固定实测均值和拟合参数，仅表达 MC 样本波动；不含参数退化、装置未知和实验系统误差。run 12 与 run 18 复用同一批 Am 模拟，二者不是独立 MC 验证。实测检查组也已在前期探索过，不能称为盲样本。

Co 上升沿、Am 长尾仍有有结构的残差。约 1.5% 的整体 RMSE 会掩盖局部最大约 4.6%–8.6% 的偏差，不能用“曲线看起来重合”替代残差检查。

对应的快速卷积拟合结果为共享快时间 478.76 ns、慢时间 1372.53 ns、有效 RC 94.47 ns，电子分量快份额 0.6231、暂配给 α 的 Am 主导分量快份额 0.1211。它们是**含固定 SPE 近似的有效参数**；不同初值还出现相近目标函数的另一组时间常数组合。没有把这些数值认定为 CsI 本征寿命、实际电路 RC 或 α/γ 已知材料参数。完整 MC 曲线来自独立光子与雪崩抽样，不是把实测模板拷入模拟。

## 当前没有吻合的部分

![保留绝对 ADC 尺度的电荷谱与形状分布](results/comparison/charge_shape_diagnostics.png)

电荷谱没有按源另行缩放。当前 1 mm 点源、α 相对产额 0.50、PDE 0.30、16 单元求和等假设下，Am 的高电荷群远高于实测主群；Co 的低电荷事件也过多。两类样本的总体形状分布宽度尚未重现。图中电荷分布使用质量筛选后的事件，未把近似幅度阈值当作 PHA 硬件触发；源封装未知、Co β 未被人为删去，也会影响低电荷部分。

共同 Q 比较按事先固定的区间选事件，而不是按形状挑选。Am 的 6 个入选 MC 事件在该模型下都有 α 沉积，但这不能给实测 Am 事件贴上逐事件 α 标签。更大电荷区间的形状、α/γ 成分混合、能量相关光产额和读出模型仍需一起检验。

当前基线 RMS 只匹配 run 3 训练段约 3.36 ADC，噪声为独立高斯样本；未复制实测噪声相关性和 run 12 后段 / run 18 的较大噪声。没有绝对增益或单光电子刻度时，光产额、PDE、收光与负载的乘积不可独立辨识。拟合后继续保持“无前放”，没有通过添加虚构放大器改善幅度。

## 继续工作的优先顺序

1. **约束幅度链和几何假设。** 尽量从现有记录找出阵列后缀、接入单元数/位置、并联或求和拓扑、负载/端接、源封装。若仍无法恢复，则在预先列明的候选配置下分别报告结果，不选一个“最像”的配置当作已确认装置。
2. **仅在训练段联合标定。** 共享 SiPM/电子学参数，使用 γ 电荷谱约束总光输出尺度，并在明确“Am 主导带暂配 α”的条件下约束粒子相关光产额；同时检查源距、封装和触发选择的退化。避免分别给两条曲线任意乘一个幅度因子。
3. **检查剩余波形偏差。** 用现有预触发波形建立相关噪声模型；在训练段检验受约束的上升沿/读出响应及能量相关发光模型。固定参数后再检查 run 3 / 12 后段与 run 18，保留所有失败或偏离结果。
4. **参数方案冻结后扩大统计。** 增加共同电荷区间的 MC 数量，按相同 Q 分箱比较幅度、上升沿、长尾、比值及分布宽度，并做 Mylar/材料步长与光学参数敏感性检查。现阶段大量重复未标定的高光产额模拟，不能解决电荷谱系统偏差。

当前可用于论文的方法框架和研究诊断；尚不足以写成“模拟已验证整套探测器响应”或据此给出真实 α 接受率 / γ 泄漏率。
