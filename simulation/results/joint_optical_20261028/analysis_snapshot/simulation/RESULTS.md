## 当前结果：联合参数筛选与完整光学复核（2026-10-28）

**两种源的绝对平均波形幅度比上一轮更接近实测，但电荷谱仍不吻合，尚不能宣称完整探测器响应已验证。** 工程保持 GAGG 风格的 `include/`、`src/` 和必要 Geant4 类；新增的 Python 程序负责参数扫描和分析。下图中的新模拟经过实际核衰变、材料能损、光学输运和 SiPM 数字化，不是把实测模板复制到输出。

预先固定尺度的 Q/门比分位数诊断损失从 63.72 降到 11.42；该量用于候选排序，**不是 χ²、似然或拟合显著性**。后段及 run 18 也保留了分布偏差；run 18 的 Q 中位数相对偏差约 −26.6%。这些检查数据此前已探索，未进入本轮联合拟合，也不能称为盲验证。

### 输入范围与硬件触发审计

采用的 run 3、7、10–14、18 的现存 `settings.xml` 均为 `COARSE_GAIN_X4`。[CAEN DT5730 规格](https://caen.it/product/dt5730-dt5730s/)将 X4 对应为 **0.5 Vpp**，旧模拟用的是假设的 2 V。新候选使用 0.5 Vpp；但部分 run 目录复用过，现存设置与历史 BIN 的完整关联尚未证实，因此没有把它升级为确定的历史采集条件。输入粗增益也不同于 PHA 能量数字增益或外接前放。记录见[配置审计](results/settings_audit_20261028/settings_audit.json)。

[CAEN DPP-PHA 说明](https://caen.it/products/dpp-pha/)采用 RC-CR² 触发。仅用保存的 96 ns 延迟、4 点平滑构造 FIR 差分诊断时，已有 run 12 训练波形约 9.6% 不能通过当前名义 160 阈值；这说明该简化和历史设置不足以重放硬件选择，**不是测出了 9.6% 的触发损失**。因此它没有进入拟合，200 ADC 也仅是双方共同分析阈值，不是探测效率或硬件触发模型。详见[触发代理核查](results/trigger_proxy_20261028/trigger_proxy.json)。

### 输运扫描与冻结的候选

新增 schema 5 保存 `edep_origin_species_MeV`，把六类衰变来源与三类实际沉积粒子（α、e±、其他）交叉记录，检查两方向能量和的一致性。这保留 α 后代次级电子对发光的贡献。真正的输运模式同时关闭闪烁与数字化，ADC 数组为空，波形工具会拒绝此类文件。

完成 9 个场景、每场景 10000 次父核衰变，共 **90000 次 Geant4 能量输运**：Co 在 1 mm 源距扫描 0 / 0.25 / 0.5 mm 铝出口片；Am 扫描 1 / 10 / 20 / 25 / 30 / 35 mm 空气间隙。铝片是宽 20 mm、距源 0.01 mm 的有限平面假设，不是已知源封装。Am 仍保留 5 μm Mylar。扫描不产生可用于比较的 ADC，也不以事件比例替代实验效率。

用输运沉积库和上一轮完整 MC 导出的响应系数进行训练段筛选，保存全部 22680 个 Am 参数网格点及 Co 候选。筛选代理的误差先与上一轮完整 MC 核查，选中后另用新随机种子运行完整光学模型。

### 工程核查、归档及下一步

Geant4 11.4.2 / ROOT 6.34.10 干净重编译后，**14 项继承内核检查 + 8 项集成检查全部通过**；新增测试验证关闭数字化的空 ADC、来源×粒子能量守恒、可选出口片和无效几何拒绝。波形特征改为分批计算，在旧样本上与原结果逐数值一致，避免大批 MC 分析占用过多内存。

## 历史版本：敏感探测器、边界修正与来源诊断（2026-10-27）

已补齐 `TrackingAction` / `TrackInformation`、`SiPMSD` / `SiPMHit`，使用 Geant4 的命中集合与数字化集合。工程继续采用 `include/`、`src/`、`macros/` 结构。14 项继承内核检查、7 项集成检查全部通过，包括两种源的随机种子重放、宏/命令行等价、来源守恒、边界状态及实际几何导出。

发现并修正了一处物理计分错误：旧版只判断光子 post-volume 是否叫 `Sensor`，会把一部分发生菲涅耳反射的光子也记作入射并终止。核查样本的 16124 个旧版命中中有 191 个属于反射，约 1.18%；这个比例仅属于该 6 事件样本。现在 `SiPMSD` 只接受透入状态，反射光子继续输运。详见[边界核查记录](results/sd_boundary_audit_20261027/finding.json)。**旧版逐事件重放曾通过，但不能证明旧版边界物理正确。**

新 ROOT schema 为 4。本轮重新生成 Co 400 次、Am 240 次衰变，保持原有效光学/读出参数，未重新拟合。两批文件均正常完成并通过来源能量、光子、雪崩电荷及计数检查；记录的 725015 / 4064202 个 SiPM 入口光子均为折射透入状态。最大相对电荷平衡误差约 1.66×10⁻¹³ / 2.02×10⁻¹³。边界修正改变后续随机数消耗，不能把新旧同编号事件当作配对样本来估计修正效应。

- Co 的 125 个通过质量筛选的事件中，84 个由衰变电子后代贡献 ≥90% 雪崩电荷，36 个由 γ 后代主导，5 个混合。衰变电子包括 β、转换及原子退激电子。无封装源与实际触发选择是低电荷部分的重要待检验因素；不能直接删掉这些事件以追求吻合。

### 接下来标定的具体顺序

1. 在已有配置与记录中约束源封装、接入通道、求和负载和触发；无法确认的量保留为候选场景。距离扫描单独不足以确定真实源距。
2. 在 run 3 / 12 训练段联合约束共享输出尺度与读出响应、源距和粒子相关光产额；显式保留 α 次级电子发光贡献。以未缩放 ADC 波形、Q 谱和短长门比同时判定，避免只优化归一化均值。
3. 冻结候选参数后再增加共同 Q 内的 MC 事件，并检查后段与 run 18。给出已探索检查的边界，继续保留 Am γ、源成分和选择条件差异。

## 当前没有吻合的部分

![保留绝对 ADC 尺度的电荷谱与形状分布](results/comparison/charge_shape_diagnostics.png)

电荷谱没有按源另行缩放。当前 1 mm 点源、α 相对产额 0.50、PDE 0.30、16 单元求和等假设下，Am 的高电荷群远高于实测主群；Co 的低电荷事件也过多。两类样本的总体形状分布宽度尚未重现。图中电荷分布使用质量筛选后的事件，未把近似幅度阈值当作 PHA 硬件触发；源封装未知、Co β 未被人为删去，也会影响低电荷部分。

共同 Q 比较按事先固定的区间选事件，而不是按形状挑选。Am 的 6 个入选 MC 事件在该模型下都有 α 沉积，但这不能给实测 Am 事件贴上逐事件 α 标签。更大电荷区间的形状、α/γ 成分混合、能量相关光产额和读出模型仍需一起检验。

当前基线 RMS 只匹配 run 3 训练段约 3.36 ADC，噪声为独立高斯样本；未复制实测噪声相关性和 run 12 后段 / run 18 的较大噪声。没有绝对增益或单光电子刻度时，光产额、PDE、收光与负载的乘积不可独立辨识。拟合后继续保持“无前放”，没有通过添加虚构放大器改善幅度。

## 继续工作的优先顺序

1. **约束幅度链和几何假设。** 尽量从现有记录找出阵列后缀、接入单元数/位置、并联或求和拓扑、负载/端接、源封装。若仍无法恢复，则在预先列明的候选配置下分别报告结果，不选一个“最像”的配置当作已确认装置。
2. **仅在训练段联合标定。** 共享 SiPM/电子学参数，使用 γ 电荷谱约束总光输出尺度，并在明确“Am 主导带暂配 α”的条件下约束粒子相关光产额；同时检查源距、封装和触发选择的退化。避免分别给两条曲线任意乘一个幅度因子。
3. **检查剩余波形偏差。** 用现有预触发波形建立相关噪声模型；在训练段检验受约束的上升沿/读出响应及能量相关发光模型。固定参数后再检查 run 3 / 12 后段与 run 18，保留所有失败或偏离结果。
4. **参数方案冻结后扩大统计。** 增加共同电荷区间的 MC 数量，按相同 Q 分箱比较幅度、上升沿、长尾、比值及分布宽度，并做 Mylar/材料步长与光学参数敏感性检查。现阶段大量重复未标定的高光产额模拟，不能解决电荷谱系统偏差。

当前可用于论文的方法框架和研究诊断；尚不足以写成“模拟已验证整套探测器响应”或据此给出真实 α 接受率 / γ 泄漏率。
