# CsI(Tl)–SiPM 源测波形的窗口依赖、跨 run 差异与响应模型检验

工作稿，2026-10-28。本文采用统一的正式分析队列；旧 phase2 数值作为历史结果保留，不与本稿的误差区间混用。当前稿件尚未按目标期刊排版，装置中未能追溯的参数明确保留为未知。全部结论限于已有记录、分析选择和所考察的响应模型。

## 摘要

研究一套无前放的 10 × 10 × 10 mm³ CsI(Tl)–SiPM 阵列读出系统，利用既有 ²⁴¹Am 和 ⁶⁰Co 源测波形，量化积分窗口、跨 run 变化及前向响应模型的适用范围。从 8 个已确认 run 的 468496 条记录中确定 40795 条共同电荷范围内的分析波形，其中 3997 条用于方法训练。对积分比、负平均时间和主成分投影进行配对块重采样，每次重新学习主成分并估计混合模型参数。3 μs 下，后两者相对积分比的形状 FOM 中位数差分别为 0.234 和 0.165，条件 95% 区间为 0.096–0.305 和 0.124–0.203；二者之间的差值区间包含零。在等电荷分箱权重及相近形状条件下，两次名义 53.2 V 的 ²⁴¹Am 测量，其 50 ns 滤波、500–900 ns 局部残差统计量相差约 57%，该差异在本次质量与基线检查中保留。Geant4 完整衰变和原生 SiPM 数字化能产生接近实测的平均形状，但共同快响应候选仍分别高估 Co 和低估 Am 的短时起伏。追加按采集 run 训练的经验随机残差后，同 run 后段三个尺度的起伏均值偏差约在 5% 内，但电荷分布、部分形状特征及跨 run 迁移仍有差距。结果说明，平均形状及单一分离指标不足以验证该读出链的完整响应。源身份不作为逐事件粒子真值，本文不据此报告 α 接受率、γ 泄漏率或能量甄别阈值。

关键词：CsI(Tl)；SiPM；数字波形；脉冲形状；块重采样；Geant4。

## 1. 研究问题及已有工作的关系

本文检验一个具体问题：在同一批已保存波形中，有限积分窗口下的方法比较和平均波形吻合，能在多大程度上描述跨 run 的逐事件响应？实验分析给出窗口与状态变化的量化结果，前向模拟检验平均形状之外的统计量。

CsI(Tl) 的数字积分、加权形状分析和带宽比较已有系统研究。Skulski 与 Momayezi [1] 已讨论相同光输出下的数字方法；Bondí 等 [2] 已将 CsI(Tl)–SiPM 测量与 Geant4 光学模型比较；Teranishi 等 [3] 已分析无放大器读出中的饱和、恢复及电压效应。因此，采用 PCA 或搭建 Geant4 工程本身不是本文的创新主张。

## 3. 分析与不确定度

### 3.1 波形与形状指标

以前 128 点均值估计基线，主峰之前最后一个 10% 幅度上升交点定义 t₁₀。积分采用其上侧整数采样点为锚点，起点为前 20 点，约 −40 ns。短门终点为 +500 ns，长门终点分别为 1、2、3、4 μs；后者表示积分终点而非总门宽。

比较短长积分比、负平均时间和第一主成分投影。PCA 输入为每 20 点积分的波形分块除以相应长门电荷，训练时每个 run × Q 箱等权，投影方向按与训练积分比的正相关固定。主分析终点为 3 μs，其他终点属于窗口敏感性研究。

### 3.2 形状 FOM 与配对块重采样

每个 Q 箱以共享位置、宽度的两个高斯核心和宽 Cauchy 项拟合两种源数据，各源混合权重独立。核心按分数排序为 L/H；FOM = 核心间距 / 两个 FWHM 之和。Cauchy 的中心、尺度由当次训练样本分位数估计，随后在该次拟合中固定。FOM 描述统计形状分离，不是分类正确率。

主分析使用 **256 次、长度 64 个原始事件序号的非重叠块 bootstrap**，两 run 分别重采样；原始训练跨度内的空块也纳入抽取。每次抽样对所有方法、Q 箱和窗口共用事件重数，重新学习 PCA，并重新估计 Cauchy 参数及高斯混合模型。报告六箱 FOM 中位数之差的百分位区间。另在 3 μs 下以块长 32、128 各做 128 次检查。本次 23040 个重采样拟合均收敛且未触及宽度下限。

所有区间条件于已选数据、固定 Q 边界、确定性子样本和模型；它们不包含装置未知量、标签不确定度或所有研究者选择。区间未作多重比较修正。为减少计算开销，对 EM 内层做等价 C++ 实现；72 个基准拟合的 FOM 最大绝对差为 4.44×10⁻¹⁶，另核对了 3 个重采样/背景尺度情景。

### 3.3 跨 run 与局部协方差

跨 run 检查固定主队列训练得到的 3 μs 方法。各共同 Q 箱内两组均至少 20 条才比较经验 KS 距离、中位数位移和整个分数分布的 IQR 比；有支持的箱等权。额外给出等样本量重复取样和仅参考组的 IID 抽样范围，后者是有限样本量背景尺度，不是时间相关零假设的检验或 p 值。跨 run 区间使用同一批 256 次训练重采样的 PCA 参数和参考事件重数，检查段另按原序号块重采样。

局部分析沿用 `ceil(t₁₀)` 锚定且不插值；减去 50、102、202 ns 居中滑动平均及各局部窗的时间均值。脉冲窗为 0–400、500–900、1200–1600、2200–2600 ns，基线窗为 −600 至 −200 ns。按每事件局部脉冲均值归一残差，在 Q/形状分组内扣除可重复跨事件均值结构，计算脉冲减基线的零延迟跨事件协方差。采用 n/(n−1) 有限样本因子，负项保留。

run 12/18 前段采用相同六个 Q 箱等权，并比较全部所选形状与 0.30≤短长比<0.35 子样本。每次块重采样均重新估计分组均值；主块长 64 做 512 次，32/128 各做 128 次。本稿的区间仅针对零延迟量，原完整时延诊断另行保留。这一统计量仍含形状变化、对齐、电子学和非平稳性，不等于单独辨识的雪崩噪声或增益。

为检查每段 3000 条的上限，追加读取 run 12/18 原始前 60% 中全部合格波形，仅复核 **50 ns 滤波、500–900 ns 局部窗**这一终点，不改变主队列。全量比较采用两 run 均有支持的短长比 <0.40 分层，另保留 0.30–0.35 和不分形状的检查；全量 run 18 中另有 2 条比值 ≥0.40 的事件，单列计数，不赋予粒子或坏事件标签。将共同 Q 等分为 6、12、24 箱，每箱两 run 均至少 10 条。全量与冻结子样本共享每次原序号块抽样，以块长 64 的 512 次、块长 128 的 256 次重估分组均值及两种样本结果之差。前 60% 内的四个采集序号区间另作点估计检查，各区间使用相同的共同支持 Q 箱；它们不代表四个等长实时时段。

### 3.4 Geant4/SiPM 与模拟误差

Geant4 11.4.2 模拟 ²⁴¹Am、⁶⁰Co 的完整衰变、能量沉积、双分量闪烁及光学输运，保留 Am 的 γ、次级电子和零沉积父事件。原生 `SiPMSD`、`SiPMDigitizer` 执行光子接收、PDE、微胞恢复、雪崩电荷、读出响应、噪声和 ADC。工程使用独立 `include/`、`src/` 和各必要 Geant4 类。[实现与条件参数](../../simulation/README.md)

当前模型沿用 16 单元求和、Co 源距 1 mm 加 0.25 mm Al 出口片、Am 源距 30 mm 等条件假设；它们不是补得的实验事实。名义过电压 3 V、增益 1.7×10⁶、PDE 0.30 等也不是独立校准结果。平均形状和基线噪声约束来自训练段；没有用检查段重新拟合本轮候选。

对已有 2000 个 Co、12000 个 Am 父衰变，保留同一光子历史重放响应候选。原慢响应为 2/29 ns SPE 与 94.47 ns RC；双路径候选加入 2/5 ns、无额外 RC 的快支路，f 为积分电荷份额。参数 f=0.10 是既往筛选中的描述性最优点，追加 AP 概率 0.15 是看过筛选后的探索情景；共同 Q 样本分别为 72/86 和 61/88 条。这些重放不增加独立输运统计。

对每种源做 512 次全父衰变多项式重采样，包含未产生可用波形的父事件；不同候选共享同一次父事件重数。实测训练事件另做块长 64 的重采样并在候选之间共享，分别报告 MC 条件误差和实测加 MC 条件误差。几何、器件假设及自适应候选选择的不确定性不在这些区间内；候选被选中的过程未纳入重采样。

进一步检查共同电荷范围内的不同 Q 占比。保持候选参数不变，在原六箱中选取实测至少 20 条、三个 MC 候选各至少 10 条的共同支持箱，令实测与所有候选使用相同的箱权重。以等箱权为主，另以固定的实测箱占比及 MC 每箱至少 5 条作敏感性检查。支持范围按源分别确定，缺失箱不外推；箱内连续 Q 分布仍可能不同。512 次父事件与实测块联合抽样使用固定的支持箱和目标权重，遇到空箱的抽样记为无效并报告数量，不在抽样过程中临时缩减支持范围。

## 4. 结果

### 4.1 窗口效应与方法差值

| 长门终点 | QDC 的六箱中位 FOM | 负平均时间 | PCA |
| --- | ---: | ---: | ---: |
| 1 μs | 1.266 | 1.386 | 1.363 |
| 2 μs | 2.018 | 2.192 | 2.157 |
| 3 μs | 2.430 | 2.665 | 2.595 |
| 4 μs | 2.646 | 2.779 | 2.826 |

3 μs 的配对差值如下。负平均时间与 PCA 相对 QDC 的区间高于零；二者之间的区间跨零，因此不能宣布二者存在稳定优劣。结果是六箱中位数比较，不意味着每个箱均有同样排序。

| 比较 | 中位 FOM 差 | 配对条件 95% 区间 |
| --- | ---: | --- |
| 负平均时间 − QDC | +0.234 | [0.096, 0.305] |
| PCA − QDC | +0.165 | [0.124, 0.203] |
| PCA − 负平均时间 | −0.069 | [−0.146, 0.070] |

块长 32/128 下保留同样的区间符号结论。在高斯核心模型内，三个相邻窗口增量的条件区间均高于零；4−3 μs 增量区间约为 QDC [0.184, 0.270]、负平均时间 [0.021, 0.248]、PCA [0.193, 0.292]。这些探索性结果支持当前记录范围内的晚期信息有用，不证明 4 μs 是全局最优终点。

![图 2：方法和窗口的配对比较](results/publication_20261028/figures/fig02_methods_windows.png)

图 2：点为原队列估计，线为配对块重采样的条件 95% 百分位区间，PCA 与混合模型在每次重采样中重估。右图比较的是中位数之差，而非逐箱差值的中位数。

保留硬件位、严格前触发、排除再次上升和替代近期基线后，3 μs 中位 FOM 的顺序均未改变。Cauchy 尺度乘 0.5/2 的影响很小，因为高斯主拟合的宽扰动权重已接近零，不能据此宣称所有背景或峰形假设均无影响。查看高斯结果后追加固定自由度 Student-t 核心诊断，使用各分布实际 FWHM：ν=5 时三方法为 2.954/3.193/3.145，ν=10 时为 2.696/2.938/2.873。绝对值明显依赖峰形，点估计排序保持不变；该追加检查没有另行计算全套区间，也不据此择优报告较大 FOM。[统计区间](results/publication_20261028/paired_uncertainty.json)；[核心模型检查](results/publication_20261028/core_model_sensitivity.json)。

### 4.4 平均波形接近不能代替完整响应检验

整体起伏指标 F 为 500–2500 ns 滤波残差方差减去 −600 至 −200 ns 基线残差方差，再除脉冲窗平均信号；报告每事件比值的均值，单位 ADC。它不同于上节扣除分组均值的 400 ns 局部协方差。

| 数据 / 响应 | Co：F₅₀ / F₁₀₂ / F₂₀₂ | Am：F₅₀ / F₁₀₂ / F₂₀₂ |
| --- | --- | --- |
| 实测训练队列 | 0.08767 / 0.16599 / 0.30049 | 0.22348 / 0.45701 / 0.85465 |
| 原响应 | 0.01196 / 0.06442 / 0.24614 | 0.01119 / 0.06896 / 0.26360 |

### 4.5 采集条件相关的经验残差可以改善起伏，但不等于物理模型完成验证

为进一步描述实测波形，在原生数字化中增加信号相关 Gaussian FIR 残差及均值为 1 的对数正态事件方差乘子。其方差与无噪声信号 ADC 成正比，零信号处为零；不修改光子、雪崩电荷或无噪声信号。257 tap 的残差谱分别由 run 3/12 前段训练，三个 F 均值与平均形状共同选择 105 ns RC，事件间方差变化随后由训练 F₅₀ 方差约束。后一步是自适应模型扩展，不作为预注册检验。模块不读取核素身份；不同 run 的经验系数不解释为核素依赖的 SiPM 增益。[完整模型、训练过程及候选记录](../../simulation/RESULTS.md)

冻结配置后新增 4000 个 Co、24000 个 Am 完整 Geant4 衰变，在共同 Q 内分别得到 120/181 条可比波形。同 run 后 20% 的归一化平均形状 NRMSE 为 2.17%/1.08%，F₅₀ 偏差为 +0.08% [−4.38%, +4.72%] / +4.20% [+1.39%, +6.79%]，另两个尺度的点偏差也在约 5% 内。区间条件于拟合后的参数，Am 仍保留可分辨的小偏差。新随机种子增加了独立模拟统计，实验检查段则已经被探索。

该校准尚未复现共同 Q 内的电荷谱；Co 后段峰值相对 t₁₀ 的中位时间为模拟 232.5 ns、实测 197.6 ns，短长门比分布也有偏移。Am 后段基线 RMS 中位数为 3.38/5.68 ADC。把 run 12 校准移到 run 18 的冻结检查子样本，F₅₀ 仍偏高 67.2% [63.5%, 71.0%]，即使平均形状 NRMSE 只有 1.17%。因此新增残差说明训练条件下的协方差能够被经验描述，但不能证明已找出真实电路或统一响应机制。[数值及区间](../../simulation/results/signal_fluctuations_20261028/waveform_validation.csv)、[未缩放幅度的波形示例](../../simulation/results/signal_fluctuations_20261028/independent/individual_native_calibration.png)、[形状和基线检查](../../simulation/results/signal_fluctuations_20261028/waveform_feature_checks.json)。

## 5. 讨论与结论范围

在当前统一队列和高斯核心定义下，晚期波形信息提高形状分离；3 μs 的负平均时间与 PCA 均优于 QDC 的六箱中位 FOM，但二者的配对差值尚不能确定排序。峰形替代模型改变绝对 FOM，跨 run 宽度指标也会受到支持区间和前触发质量影响，因此“算法最优”或“探测器稳定”的结论必须带上条件。

相同 Q 权重和相近统计形状下，run 12/18 的局部残差差异在本次检查中较稳定；取消子样本上限和细化 Q 分箱后仍保留。与此并行，平均形状接近的共同快响应候选仍不能同时复现两种源的多尺度起伏和电荷分布，在有限共同支持内匹配 Q 箱占比也未消除短时起伏的相反偏差。按 run 训练经验残差改善了同 run 的起伏，却未解决电荷谱、全部形状特征和跨 run 迁移。这些证据支持采用平均形状之外的统计约束检查该读出链，而不支持从单条匹配曲线反演唯一材料或器件参数。

仍需保留的限制包括：原始 run 与配置的关联不完整；真实求和电路、光学耦合、源距和温度缺失；ADC 电荷不等于沉积能量；源混合与基线选择相关；所有检查数据已被探索；确定性子样本与块方法不能涵盖所有非平稳过程；模拟采用的几何、PDE、增益和时间参数存在退化。当前不报告 α 接受率、γ 泄漏率、样本粒子纯度、keVee 阈值、温度稳定性或测得的本征时间常数。

本文已具备同队列数据、配对不确定度、系统检查和模型偏差的可追溯初稿材料。投稿前仍需作者确认能补得的装置记录、明确拟投文章的贡献范围，并按期刊要求整理作者信息、参考文献和图表；已有本地对照不能保证新颖性或录用。
